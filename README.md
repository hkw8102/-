# PLUSWIN — website renewal preview

**Live preview: https://hkw8102.github.io/-/**

A 3-language (日本語 / 한국어 / English) prototype of the renewed **pluswin.net** site for
プラスウイン株式会社 (PLUSWIN Entertainment), Osaka.

- `index.html` — page (static, no build step)
- `styles.css` — design system & layout
- `app.js` — content data, JP/KR/EN translations, event detail drawer + guidelines, past-event archive, rental form
- `assets/` — photos, event posters, official logo, subset webfonts

Language switcher: **JP / KR / EN** in the header (also `?lang=ja|ko|en`).
Open `index.html` directly, or serve the folder with any static server.

Content: live hall (PLUSWIN HALL OSAKA) and venue rental, event planning & production,
upcoming shows (KEN / ERU / HYUK / JINHO), **past-event archive (53 shows, 2023–2026)** with
poster grid and year filter, event detail drawer with collapsible **guidelines & precautions**
(JP/KR/EN), hall specs, rental enquiry form, company profile.

Fonts: Noto Sans JP / KR, subset to the characters used on the page (OFL).

This is a preview build — not the production site. Search indexing is disabled.
